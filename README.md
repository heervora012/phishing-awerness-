🎣 Phishing Awareness Training Module
An interactive, terminal-based Python training program that teaches users how to recognize, resist, and report phishing attacks and social engineering tactics — complete with quizzes, scenario simulators, and a completion certificate.
⚠️ For educational purposes only. Use in authorized environments.
✨ Features
• 13 interactive menu options — learning modules, quizzes, simulators and reference guides
• 5 phishing types covered — Email, Spearphishing, Whaling, Clone Phishing, Smishing/Vishing
• 7 social engineering tactics — Authority, Urgency, Fear, Trust, Reciprocity, Curiosity, Consensus
• Interactive quiz — multiple-choice questions with scored results
• Email simulator — analyze real-world phishing email examples
• Real-world scenarios — CEO fraud, tech support scams, password reset attacks
• Vulnerability self-assessment — identify your own security blind spots
• Certificate of completion — auto-generated on finishing the program
• Progress tracking — score and module completion saved per session
📋 Requirements
• Python 3.x
• No external libraries required — uses only the standard library
🚀 Usage
python3 server.py
You will be greeted with a banner, prompted for your name, and taken to the main menu.

💡 Example Scenarios
The Urgent CEO Request
You receive an email from a Gmail address similar to your CEO's asking for a $50,000 wire transfer — confidentially.
✅ Correct action: Do NOT transfer. Verify via a known phone number. Report to IT immediately.
The IT Support Scam
"Microsoft Support" calls claiming your computer is compromised and asks for remote access.
✅ Correct action: Hang up. Contact your real IT department using a known number.
The Password Reset Email
A professional-looking Microsoft email says your password expires in 24 hours — but hovering over the link shows a different URL.
✅ Correct action: Don't click. Type microsoft.com directly in your browser.
